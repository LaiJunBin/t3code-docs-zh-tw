## 這份文件怎麼讀

- **正文是官方英文文件的翻譯**，每一頁最下方都標示對應的原文檔案，可以點過去對照。
- **有顏色的方框是本站加上的內容**，分成「範例」、「補充說明」、「白話解釋」三種，右上角都有「本站補充」字樣。想只看官方內容的話，按右上角的「補充」按鈕就能全部隱藏。
- Thread、Provider、Worktree 這類產品名詞保留英文，底下有虛線的詞可以點進[名詞對照表](./guide/glossary.md)。
- 連結旁邊標示「英文」的，代表那一頁還沒翻譯，會直接開啟 GitHub 上的英文原文。

T3 Code 包含第三方軟體，以及經過改編的素材。要閱讀它們的授權條款與著作權標示：

- 在網頁版和桌面版，開啟 **Settings → General**，在 **About** 底下找到 **Open source licenses**，然後選擇 **View licenses**。
- 在手機版，開啟 **Settings → About T3 Code → Open source licenses**。

這個頁面會列出版本（有的話）、授權識別碼，以及 T3 Code 裡有哪些部分包含或使用了這個項目。這也涵蓋那些 T3 Code 不隨附、而是在需要時才安裝的選用裝置工具。選取其中一列，就能閱讀完整的聲明文字。用搜尋欄位可以尋找套件、版本、授權或 app 元件。

每個終端機會在它的 environment server 上保留最多 5,000 行、8 MiB 的捲動紀錄（scrollback）。只要達到其中一個上限，T3 Code 就會移除最舊的輸出。很長的一行可能會從開頭被截短。新的終端機輸出不會被截斷。

:::plain 哪些輸出會不見
兩個上限是「先到先算」：輸出超過 5,000 行，或是總量超過 8 MiB，最舊的部分就會被丟掉，最新的輸出一定留著。所以跑了很久的 dev server 或很長的測試輸出，往回捲時可能已經看不到最前面的內容。需要完整保留的輸出，請在指令裡自己導到檔案。
:::

這些上限會在你重新連線時，以及 T3 Code 還原已儲存的終端機歷史紀錄時套用。Client 顯示的捲動紀錄，可能比 server 保留的還要少。

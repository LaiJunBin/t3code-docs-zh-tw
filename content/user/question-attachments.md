當 agent 提出的問題可以接受自訂答案時，使用 **Attach files**，或是把圖片貼到答案欄位裡。在手機版，用附件按鈕選擇照片或檔案。你可以只送出檔案，也可以搭配選取的選項，或搭配自己輸入的答案一起送出。

:::example 用一張截圖來回答
agent 問你「畫面上跑版的是哪一個區塊？」，並且允許自訂答案。與其用文字描述，你可以直接把截圖貼進答案欄位，再補一句「紅框的這一塊」，然後送出。如果問題只提供固定選項、不接受自訂答案，就不會出現附加檔案的功能。
:::

在不同問題之間切換時，每個問題會各自保留它的附件。你平常的 prompt 草稿則是分開的，不受影響。送出之前請等上傳完成；上傳失敗的檔案請重試或移除。如果回覆送出失敗，草稿會保留下來，讓你再試一次。

檔案會上傳到執行這個 Thread 的 environment，遠端的 environment 也一樣。agent 會連同你的答案收到這些已儲存檔案的路徑，並可以用它現有的工具開啟它們。只接受預設選項的問題不提供附件功能。舊版的 server 需要更新之後，這個選項才會出現。

已送出的附件會留在 Thread 的歷史紀錄裡。Revert 一個 Thread 時，屬於被捨棄答案的附件會被移除；刪除 Thread 時，使用的是和其他附件相同的檔案清理方式。同一組答案總共最多可以附加 100 個檔案，單一檔案大小和圖片總大小的上限，和一般的 composer 相同。

:::note 上限的實際數字
和一般訊息相同的那些上限是：每張圖片最大 10 MiB，圖片總和最多 80 MiB，其他檔案每個最大 50 MiB（另受 environment 的上限限制）。差別在於 100 個檔案的額度是「同一組答案」合計，不是每個問題各 100 個。完整說明見[附加檔案](./composer.md#attach-files)。
:::

指令面板開著的時候會一直保有焦點。關閉之後，焦點會回到訊息輸入框（composer）。指令面板或模型選單開著時，數字快捷鍵選的是它裡面的項目，而不是切換 Thread。模型快捷鍵在 Settings 裡和在 composer 裡都可以使用。要自訂這些快捷鍵，請看[快捷鍵](./keybindings.md)。

:::plain 「焦點」指的是什麼
焦點就是「現在按鍵盤，字會打到哪裡」。這一頁說的是 T3 Code 怎麼決定焦點的去向，讓你不必一直用滑鼠點回輸入框。
:::

如果終端機還在啟動時，你已經回去繼續打字，那麼終端機準備好之後，焦點仍然會留在 composer。如果是你明確地開啟或切換到某個終端機，焦點還是會移到那個終端機上。
